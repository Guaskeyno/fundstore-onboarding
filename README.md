# Fundstore Onboarding

Clickable desktop design prototype of the Fundstore sign-up and first-login journey, built from the Figma designs.

Single self-contained `index.html`: styles, scripts, images and Phosphor icons are embedded; Onest and Merriweather load from Google Fonts. No data entered in the prototype is sent anywhere.

Deep links: `#app/dossier`, `#app/fondi`, `#app/movimenti`, `#app/esperti`, `#app/posta`, `#app/profilo`.
